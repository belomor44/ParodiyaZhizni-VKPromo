# ПАРОДИЯ ЖИЗНИ | VK PROMO — прототип 0.1

## Что умеет прототип
- Чёрно-красный интерфейс.
- Открывает поиск публикаций ВКонтакте по ключевым словам.
- Позволяет открыть указанное сообщество.
- Помогает подготовить комментарий и скопировать его.
- Не запрашивает пароль ВК и не публикует комментарии автоматически.

## Ограничения
Это начальный прототип: результаты поиска открываются в самом ВКонтакте, а не собираются внутри приложения. Для встроенной выдачи понадобится интеграция с официальным VK API и подходящая авторизация.

## Сборка APK
Проект можно собрать в облаке через GitHub Actions. Файл `.github/workflows/build-apk.yml` содержит workflow сборки.
